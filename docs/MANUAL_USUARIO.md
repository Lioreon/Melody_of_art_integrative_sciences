# Melody Motion — Manual técnico-pedagógico

## Edición pedagógica, institucional y científica · 2026

**Autoría:** A. Owsky  
**Línea:** Ciencias Integrativas · Bolívar, Ecuador  
**Contexto pedagógico:** Escuela de Música Matiaví - Salinas

Este documento resume la estructura del manual institucional de Melody Motion y sirve como referencia textual versionable dentro del repositorio.

## Propósito

Melody Motion es una plataforma educativa experimental que traduce movimiento corporal en relaciones musicales mediante visión computacional, representación progresiva y retroalimentación auditiva.

La guía cumple tres funciones:

1. guía de uso;
2. referencia pedagógica;
3. documento institucional para presentación ante docentes, instituciones y colaboradores.

## Principio rector

> La tecnología educativa no debería maximizar la interacción con la pantalla; debería maximizar las relaciones que el aprendiz puede construir a través de ella.

La arquitectura conceptual se resume como:

`Posición → Símbolo → Sonido → Tiempo`

## Cuatro dominios

### Instrumento
Pregunta: **¿qué ocurre musicalmente cuando cambio altura y separación?**

La altura de las manos se relaciona con la nota; la separación se relaciona con duración/figura. La visión objetivo incorpora respuesta sonora inmediata.

### Ritmo
Pregunta: **¿qué significa una apertura concreta y cómo se sostiene?**

La progresión actual validada es:

`Explorar → Una figura → Secuencia`

La dificultad futura debe depender de vocabulario, longitud de secuencia y reducción de asistencia.

### Pentagrama
Pregunta: **¿cómo se representa y localiza musicalmente lo que hago?**

La experiencia objetivo compara:
- nota objetivo;
- nota actual;
- figura objetivo;
- figura detectada.

La ayuda se retira progresivamente hasta acercarse a lectura convencional.

### Compás
Pregunta: **¿cómo mantengo esas relaciones mientras la música ocurre?**

La visión actual propone un **acordeón corporal**: la distancia entre palmas sigue una secuencia rítmica dentro de una canción o patrón temporal.

## Seguimiento y error

La cadena debe mantenerse separada:

`Tracking → Interpretación → Dominio musical → Evaluación pedagógica → UI`

Una pérdida de seguimiento no equivale a un error del aprendiz.

## Audio transversal

Arquitectura objetivo:

`Evento pedagógico → intención sonora → motor de audio → timbre`

Esto permite conservar la lógica pedagógica aunque cambie la tecnología sonora.

## Dynamic Score

`Asistido → Ayuda reducida → Lectura → Transferencia`

La retirada de ayudas debe responder a dominio de relaciones, no a tiempo de pantalla ni puntuación arbitraria.

## Uso responsable

Melody Motion está orientado principalmente a población infanto-juvenil. El procesamiento de cámara debe priorizar privacidad y mínima recopilación de datos. Las hipótesis sobre memoria asociativa, aprendizaje y transferencia requieren validación experimental; la aplicación no es un dispositivo médico ni una prueba diagnóstica.
